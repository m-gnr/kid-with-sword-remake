# Known issues

| Issue | Severity and status | Reproduction and evidence |
| --- | --- | --- |
| Normal + Handheld performance below the P0 target (>=40 FPS) | High, open (Primary target) | Current Handheld measurement is ~21–22 presented FPS with ~27–28 ms reported GPU time and frequent 50 ms display intervals. Primary GPU bottleneck is Kokiri Forest foliage passes (~17 ms), addressable via native subword stores (`ffebfd59`). |
| Docked fullscreen performance below the P1 target | Historical reference only | Phase One observed 21.62 FPS in Kokiri Forest. Retained as historical reference; Docked is not an active optimization target. |
| Pipeline archive pulling-base loss on compaction | High, open (addressed by PR #1590) | Compacting `%05d.mtl4a` without `include_pull` discards pulling bases because `pso_save_base` shared `g_base_epoch` with vertex bases. Causes repeated pipeline compilation hitches on launch. Addressed by PR #1590 epoch splitting. |
| Single-frame white foliage flashing in Kokiri Forest | Medium, open (addressed by commit `e5f1adee`) | In Kokiri Forest, foliage flashes white for single frames because mesh stage wrapper lacks `[[position, invariant]]`, allowing slight depth mismatch between depth pre-pass and color pass (PR #1673). |
| Unified memory pressure and scene-entry upload | Medium, mitigated in fork | Phase One observed 12.37 GB of app memory. Mitigated in fork by PR #1455 (`alias_retire_idle`) and PR #1394 (`mtl_pool_buffer_addr`) in `ad998585`. |
| Blank or magenta textures after area changes | Medium, resolved in profile | Crossing into Hyrule Castle Town and Hyrule Field caused textures to read zeros with `DM_TEX_RELEASE=2`. Resolved by setting `DM_TEX_RELEASE=1` (CPU_NO_ACCESS pools only) as documented in game note. |
| Foliage atomic CAS retry contention in mesh shaders | High, open (addressed by commit `ffebfd59`) | 11 active foliage mesh shaders in Kokiri Forest execute atomic CAS loops for byte/half-word primitive indices, retrying ~4 times per store under lane contention. Solved upstream by native `uchar*` and `ushort*` stores in `ffebfd59`. |
| Unrecognized NDSR chain ending | Medium, open | Reproduce with the same settings and record the ending key, input/output sizes and fallback behavior. Historical log identifies ending `d99fbeeb53d38847` and the next-frame fallback. The Phase Two binding dump measured the terminal variant at 854 × 480 → 2560 × 1440. |
| Save compatibility across builds | High if confirmed, unverified | Record the fixture's game build and load a fresh copied save. Keep its profile, slot and both metadata and progress files together. Confirm that the experimental build can load and save independently. No incompatibility was observed in Phase One. |
| Cloned launcher waits before logging | Medium, isolated run workaround verified | Shell launch of the unmodified clone stayed in `_dyld_start` for over three minutes without a log or host child. Workaround verified: invoke the embedded `dmhost` directly with explicit resource environment variables. |

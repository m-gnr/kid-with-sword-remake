# Optimization plan

On base M3 (16 GB), **P0 is stable 60 presented FPS in Normal + Handheld (1280 × 720)** (minimum 40 actual presented FPS). **P1 is stable 60 presented FPS in Normal + Docked, if feasible** (historical reference). Preserve visual quality and normal gameplay speed in both modes. Do not use Potato settings.

Phase Four research ([09-phase-four-upstream-research.md](09-phase-four-upstream-research.md)) confirms that PRs #1455, #1447, #1394, and #1439 are already implemented in our fork (`ad998585`). ## Rebuild and resource scope

- **Host-only optimizations (PR #1590 archive/lookahead, PR #1489 table notes, presentation cadence)**: Require only recompiling `dmhost` (`make -C dm/host`), which takes ~10 seconds. They do not alter `dmsh_chain.py`'s `FILES` list, so `DMSH_CHAIN` remains `"dc815e0f38ca"`. The host reuses 100% of the existing 42,854 precompiled shaders (`b-dc815e0f38ca.img`, 11 GiB) and bundled pipeline archives.
- **Shader chain optimizations (Native subword stores `ffebfd59`, position invariance `e5f1adee`)**: Require running `dmsh_chain.py --header`, updating `dmsh_chain.h`, and recompiling the host. Because only 515 shaders out of 42,848 contain the subword store, the compilation database (`cas.db`, 13 GiB) hits for the remaining 42,333 unchanged shaders, avoiding full recompilation from scratch.
- **Workspace and scratch budget**: APFS clone (`cp -cRp`) shares disk blocks with the existing 34 GiB installation. Allow ~10 GiB scratch on the external APFS volume for experimental outputs and trace captures.

## Next validation

The [Phase Four report](09-phase-four-upstream-research.md#recommended-integration-sequence) establishes the phased integration sequence:

1. **First optimization (Host-only)**: Backport PR #1590's `ArchEpoch` pulling base retention and compacted shard ordering in `nvn_mtl.m`. Verify that pulling bases persist in `p*.mtl4a` across compaction and that prebuild logs zero pulling misses on relaunch.
2. **Second optimization (Host-only)**: Port PR #1489's remainder (`REG_POOL` and dead/transient ID retake) in `nvn_mtl.m`. Measure submit CPU time on a walking route in Normal + Handheld.
3. **Third optimization (Shader chain & host, pending approval)**: Implement native subword stores (`ffebfd59`) and mesh position invariance (`e5f1adee`). Rebuild the 515 affected shaders with `cas.db`. Conduct controlled Normal + Handheld benchmark in Kokiri Forest to measure GPU duration reduction toward the 25 ms / 40 FPS target.
